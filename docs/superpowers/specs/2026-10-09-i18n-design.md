# 界面国际化（i18n）设计：默认英文 + 中/英切换

日期：2026-10-09

## 目标

网站内容默认英文，顶栏提供语言切换按钮，可选 English / 中文，选择持久化。

## 决策记录

| 决策点 | 结论 |
|---|---|
| 默认语言 | English（不跟随浏览器语言） |
| 可选语言 | English、中文，运行时切换 |
| 持久化 | localStorage `lang` |
| 示例种子数据 | 跟随当前界面语言生成 |
| i18n 实现 | 方案 A：手写轻量模块（枚举 key + 静态字典，零新依赖） |

## 设计内容

### 1. i18n 模块（新增 `src/i18n.rs`）

- `Lang` 枚举：`En`（默认）、`Zh`；含 `as_str()` / `from_str()` 供 localStorage 读写
- **Key 为枚举**（约 70 个变体）：`t(lang, key) -> &'static str` 查静态表；match 穷尽保证编译期不漏 key、两语言齐全
- 动态文案用专用函数返回 `String`（约 6 处）：`today_progress`、`import_success_msg`、`redeem_confirm_msg`、`wish_gap`、日历「N 项」、图表 title 等
- 单元测试：所有 key 两语言非空且互不相同；插值函数输出正确

### 2. 语言状态与切换

- `App` 提供 `RwSignal<Lang>` context（同 `Credits` 模式）；组件 `move || t(lang.get(), K::Xxx)`
- 初始化：读 localStorage `lang`，无记录默认 `En`
- 顶栏暗色切换按钮旁加文字按钮（显示当前语言 `EN` / `中文`，点击切换）；切换时同步 `<html lang>` 与 `document.title`
- `index.html` 静态内容英文化：`lang="en"`、`<title>Kids Credit Station</title>`

### 3. 翻译范围

- **全部 UI 文案**：顶栏、tabs、hero 卡、空状态、导入/导出提示、5 个 sections、3 个弹窗、按钮 title / aria-label
- **日期本地化**：
  - 顶栏日期行：中「2026-10-09 · 10月9日 星期五」/ 英「Friday, October 9, 2026」
  - 日历表头：一~日 / Mo~Su
  - 月份标题：「2026年10月」/「October 2026」
  - 「今天 / 全勤 / N 项」、图表 SVG 内文字（当前积分、赚得、花掉、说明）
- **示例种子数据**：`Credits::create_kid` 增加 `lang` 参数，按当前界面语言生成默认任务/心愿（`store.rs` 默认数据中英文各一套）
- **错误信息**：`BackupError` 保持枚举，错误文案移到 UI 层走 `t()`
- **不翻译**：用户自填数据（孩子名、任务名、心愿名）；备份 JSON 格式不变（向后兼容）

### 4. 测试与验证

- `date.rs` 测试更新为带语言参数
- `cargo test` 全绿；`trunk build --release` 通过
- `trunk serve` 实测：默认英文、切换即时生效、刷新后保持、示例数据语言正确

## 约束

- 不引入新 Rust 依赖
- 备份 JSON 格式与数据层逻辑不变
- 现有 M3 样式不动，语言按钮复用 `m3-icon-btn` / outlined 风格

## 风险

- 字符串散落各组件，需逐文件梳理避免遗漏——以编译器穷尽检查 + 实测兜底
- 英文普遍比中文长，注意 tab/按钮文字不换行溢出（实测检查）
